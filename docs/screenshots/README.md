# Sakhi Screenshots

This folder holds screenshots of Sakhi for documentation, hackathon submissions, and judges.

Recommended filenames and image dimensions (taken at mobile viewport 390x844 or 360x800):

| Filename        | Screen                          | What it shows                                                                    |
| :-------------- | :------------------------------ | :------------------------------------------------------------------------------- |
| `home.png`      | Home (`/home`)                  | Today check-in status, cycle forecast, nearest care card, and quick action cards |
| `log.png`       | Daily Check-in (`/log`)         | Flow, pain area selection, mood, energy, and symptom chips with 44px tap targets |
| `calendar.png`  | Cycle Calendar (`/cycle`)       | 24-month grid with flow intensity, pain markers, and predicted next period       |
| `care.png`      | Healthcare Finder (`/care`)     | Live Geoapify search results, distance chips (5/10/25/50 km), and facility cards |
| `schemes.png`   | Government Schemes (`/schemes`) | 36 States/UTs filter, "Made for Women" tier, and check-in personalized tags      |
| `ask-sakhi.png` | Ask Sakhi (`AskSakhiWidget`)    | Streaming AI chat with clinical safety guards, and swipeable awareness cards     |

Save your PNG screenshots directly into this directory using the filenames above.
